## About me

I'm a physicist, software developer & architect as well as a Kubernetes & automation expert.
You can find more details on [my company website](https://hilling.it).

## Why this page? Isn't there enough documentation anyway?

Yes, there is. But I wanted to write at least a little bit of my own for this project. Everything else was created by [Claude](https://claude.ai):

* The actual code:
    * Backend in Go (using AWS Lambda)
    * Frontend in React/TypeScript
    * Mobile frontends for iOS and Android using one Expo codebase
* Unit tests
* Integration tests
* End-to-end tests
* Integration with [GitHub](https://github.com/guhilling/ai-assisted-todolist)
* Integration with [SonarQube Cloud](https://sonarcloud.io/project/overview?id=guhilling_ai-assisted-todolist) and [CodeRabbit](https://www.coderabbit.ai)
* [OpenTofu](https://opentofu.org) configuration files for setting up [AWS](https://aws.amazon.com) resources and deployment.
* [Perses](https://perses.dev) dashboards hosted on a [Hetzner](https://www.hetzner.com/) server.

For details, please read the great [official documentation](README.md).

It's also worth mentioning that the first implementation of this project used [Quarkus](https://quarkus.io) in the backend as I'm really fluent with [Java](https://www.java.com) in general and in Quarkus too.

For several reasons (mainly financial ones ...) I wanted a second version and I decided on purpose to choose [Go](https://go.dev) as a language because _I'm not really familiar with it_.

So for the implementation, testing and documentation I relied completely on [Claude](https://claude.ai).

Of course it's still important to make sure guardrails are in (the correct) place and the project takes the right direction ... but then again: It's really stunning what AI can do today.
